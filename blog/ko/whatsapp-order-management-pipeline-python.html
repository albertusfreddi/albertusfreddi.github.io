Webhook Verification and Idempotency Keys

Meta WhatsApp Cloud API sends asynchronous webhooks that can retry duplicate events upon network drops. Our ingestion middleware implements SHA-256 payload verification combined with Redis idempotency caches to prevent double-charging or duplicate order fulfillment.

Regex Entity Extraction with Fallback NLP

Because Indonesian customers abbreviate addresses and bank names unpredictably, we execute a fast regex tokenization step for quantities and payment proof screenshots, with an asynchronous fallback to an entity extractor when input formats deviate.

WhatsApp Webhook Order Payload Parser
from fastapi import FastAPI, Request, HTTPException
from pydantic import BaseModel
import hmac, hashlib

app = FastAPI()

@app.post("/webhook/whatsapp")
async def handle_whatsapp_order(req: Request):
    signature = req.headers.get("X-Hub-Signature-256", "")
    body_bytes = await req.body()
    # Validate payload signature against app secret
    expected = "sha256=" + hmac.new(b"app_secret_key", body_bytes, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(signature, expected):
        raise HTTPException(status_code=403, detail="Signature mismatch")

    return {"status": "dispatched", "order_id": order_data.get("id")}
