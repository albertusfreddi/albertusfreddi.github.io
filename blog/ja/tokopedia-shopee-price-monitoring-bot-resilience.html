Why DOM Scraping Fails on Indonesian Marketplaces

Modern marketplace platforms across Southeast Asia deploy aggressive anti-bot defenses: dynamic obfuscated class names, canvas-based fingerprinting, and Cloudflare Turnstile challenges. Scraping raw HTML DOM trees breaks on every weekly release.

The Reverse-Engineered Mobile API Architecture

By intercepting mobile application network traffic through an SSL-pinned proxy gateway in a staging sandbox, we extract internal GraphQL endpoints. These endpoints return clean JSON payloads with product variations, stock levels, and flash sale discounts without heavy DOM parsing.

Handling TLS Fingerprints and Token Rotation

Standard Python requests or Node fetch libraries trigger instant Akamai and Cloudflare blocks due to mismatched TLS cipher suites. Using curl_cffi or Playwright with authentic browser profiles preserves JA3/JA4 fingerprints while rotating residential proxies across Telkomsel and Indosat IP subnets.

Mobile GraphQL Token Extraction & TLS Impersonation
from curl_cffi import requests

def fetch_marketplace_sku(product_id: str, app_session_token: str):
    url = "https://gql.tokopedia.com/graphql/ProductDetailQuery"
    headers = {
        "User-Agent": "okhttp/4.9.2 TokopediaAndroid/3.245",
        "X-Device-Id": "android-prod-9a7c81d2e",
        "Authorization": f"Bearer {app_session_token}"
    }
    payload = [{
        "operationName": "ProductDetailQuery",
        "variables": {"shopDomain": "", "productKey": product_id},
        "query": "query ProductDetailQuery($productKey: String!) { productDetail(key: $productKey) { id name price { value currency } stock { status available } } }"
    }]
    resp = requests.post(url, headers=headers, json=payload, impersonate="chrome120")
    if resp.status_code == 200:
        return resp.json()[0]["data"]["productDetail"]
    raise ConnectionRefusedError(f"Rejected with status: {resp.status_code}")

Production Operational Safeguards

Aggressive scraping is neither necessary nor sustainable. We enforce exponential backoff, jittered interval delays between 2 and 5 seconds, and respect platform robots.txt to keep the client pipeline in strict compliance with Indonesian data standards.
