Scraping Indonesian Government Procurement (LPSE): Architecture & Data Pipelines

9 min read • 2026-09-24

How we built a resilient pipeline parsing tender notices across 500+ regional LPSE portals without rate-limit lockouts.

The Fragmentation of Regional LPSE Portals

While the LKPP framework powers all LPSE implementations, regional server versions vary wildly between provinces. Some portals run SPSE 4.5u4, others run outdated legacy builds with custom SSL certificates and sluggish database response times.

Distributed Crawler Scheduling and Queuing

We deployed a distributed Celery worker pool backed by Redis. Portals are clustered by regional server capacity: heavy municipal portals receive low-frequency staggered crawls, while fast national ministries run high-priority polling.

Parsing Unstructured PDF Tender Documents

Tender qualification criteria and Bill of Quantities (BoQ) are locked inside scanned PDF attachments. Using an automated OCR pipeline with Tesseract and PyMuPDF, our ingestion engine converts raw document attachments into indexed, searchable JSON schemas.

Asynchronous LPSE Tender Harvester
import httpx
import asyncio

async def fetch_lpse_tenders(client: httpx.AsyncClient, portal_domain: str):
    endpoint = f"https://{portal_domain}/eproc4/dt/lelang"
    params = {"draw": 1, "start": 0, "length": 50}
    try:
        res = await client.get(endpoint, params=params, timeout=15.0)
        if res.status_code == 200:
            payload = res.json()
            return payload.get("data", [])
    except httpx.RequestError as exc:
        print(f"Portal {portal_domain} unreachable: {exc}")
    return []

Automated Real-Time Stakeholder Notifications

Vendor sales teams receive instant Telegram and WhatsApp alerts the moment a tender matching their sub-classification (e.g. IT Infrastructure, Civil Works) is published, giving them a 48-hour head start on proposal drafting.
