Off-the-shelf vector embeddings fail miserably on casual slang. Here is our custom preprocessing pipeline that solved it.

The Failure Mode of Standard Vector Embeddings

Pre-trained vector models perform decently on formal Indonesian news articles, but collapse when handling conversational inputs like "min paket sy blm smpe pdhl udh tf kmrn". Vector cosine similarity scores plummet, causing knowledge retrieval to miss relevant order status policies.

The Colloquial Slang Normalization Dictionary

Before text reaches the embedding model or RAG retriever, we pipe inbound customer messages through a compiled finite-state dictionary mapping over 4,500 Indonesian slang contractions, phonetic typos, and regional suffixes back to standard root lemmas.

Deterministic Indonesian Slang Lemmatizer
import re

SLANG_DICTIONARY = {
    r"\bmin\b": "admin",
    r"\bsy\b|\bak\b": "saya",
    r"\bblm\b": "belum",
    r"\bsmpe\b|\bsmpai\b": "sampai",
    r"\bpdhl\b": "padahal",
    r"\budh\b|\bdh\b": "sudah",
    r"\btf\b": "transfer",
    r"\bkmrn\b": "kemarin",
    r"\bgmn\b": "bagaimana"
}

def normalize_indonesian_slang(raw_text: str) -> str:
    cleaned = raw_text.lower()
    for pattern, replacement in SLANG_DICTIONARY.items():
        cleaned = re.sub(pattern, replacement, cleaned)
    cleaned = re.sub(r'([a-z])\1{2,}', r'\1', cleaned)
    return cleaned.strip()
